# Projets IA no code — Caroline Camilleri

Portfolio de trois études de cas exploratoires, réalisées avec Claude et Claude Code sans écrire de code.

En ligne : https://ccamilleri-ux.github.io/portfolio-ia/

## Contenu

- `index.html` : accueil (présentation, trois études de cas, méthode avec l'IA)
- `cas-siplec.html`, `cas-amundi.html`, `cas-ugc.html` : études de cas
- `projets/` : les trois projets de démonstration, consultables en ligne et modifiables indépendamment
- `assets/` : feuille de style, captures d'écran, image de partage (Open Graph), favicon
- `A-COMPLETER.md` : informations à compléter

## Technique

Pages du portfolio en HTML et CSS statiques, sans JavaScript ni étape de build (les projets de démonstration utilisent un peu de JavaScript natif). Liens relatifs, compatibles avec GitHub Pages (branche `main`, dossier racine).
Seule ressource externe : Google Fonts (Inter). Aucun cookie, aucun outil de mesure d'audience.

Projets fictifs réalisés à titre de démonstration, sans lien avec les entreprises citées. Les marques citées appartiennent à leurs propriétaires.
